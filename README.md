⚽ Blue Lock Anime Landing Page

A responsive landing page project featuring the anime Blue Lock, created as a practice exercise focusing purely on HTML and CSS.

This project demonstrates core front-end skills, including layout management (using Flexbox), basic styling, and attention to detail based on a design mockup.

Features
- Responsive Layout: The design adapts to different screen sizes, ensuring usability on various devices.
- Navigation: Clear header with a logo and links to other fictional anime pages (Blue Lock, Death Note, Mashle).
- Hero Section: Prominent section with a headline, description, a call-to-action button ("Watch Season 1"), and a main image.
- Information/Characters Section: A showcase of key Blue Lock characters with their names and dynamic hover effects on their profile pictures.
- Quote Section: A dedicated section for a memorable quote from the anime, formatted distinctly.
- Call-to-Action Footer: A final banner promoting merchandise with a contrasting button ("To the Shop").
- Custom Styling: Utilizes custom fonts (Roboto) and a distinct color palette consistent with a modern, dark-themed design.

Tech
- HTML5: Structure and semantic content.
- CSS3: Styling, layout (primarily Flexbox), custom fonts, and animations/transitions (e.g., image hover effects).

Design and Layout

The layout is built using Flexbox for both major sections (header navigation, hero content, call-to-action) and minor components (character cards).

Key CSS Features
- Layout: Extensive use of display: flex and Flexbox properties (justify-content, align-items, flex-flow) for structured, adaptable content.
- Customization: The :root selector is used to set a global font, and @font-face is implemented to include the Roboto font.
- Hover Effects: Interactive styling, such as Character Images: A border color change and an outline-offset transition on the image container, combined with a subtle height increase on the <img> element for a dynamic 'pop' effect, or Buttons: Color inversion on hover for clear feedback.
- Utility Classes: Classes like .content-w80, .content-w60, and .margin-center are used for consistent content width and centering across sections.
